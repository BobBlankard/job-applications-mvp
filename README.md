# Resume Builder

A self-contained, ATS-friendly resume builder with a split-pane editor and live preview — inspired by Overleaf's UX but without LaTeX complexity.

## Features

- **Split-pane UI** — YAML source editor (left) and live US Letter preview (right)
- **ATS-optimized resumes** — single-column layout, standard section headers, system fonts, no tables or graphics
- **Cover letters** — separate YAML-driven letters with 6 professional templates and signature-style closing
- **One-page enforcement** — warning when content exceeds 8.5″ × 11″
- **Vector PDF export** — preview-matched PDF download via DOM → SVG → PDF (jsPDF + svg2pdf.js)
- **Auto-save** — content persists in `localStorage`

## Quick Start

**Open the app in Chrome** — double-click `index.html`, or drag it into a Chrome window. No server or install required.

The root `index.html` and `assets/` folder are pre-built for local file use (`file://`).

### Development

To edit the source and rebuild:

```bash
npm install
npm run dev
```

Open [http://localhost:5180](http://localhost:5180) if the browser doesn't open automatically. Source lives in `index.dev.html` and `src/`.

After changing source files, regenerate the standalone app:

```bash
npm run build
```

This updates `index.html` and `assets/` with relative paths that work when opened directly in Chrome.

## Usage

### Resumes

1. Edit your resume in YAML on the left panel.
2. Watch the preview update in real time on the right.
3. Click **Download PDF** to save `Doherty Resume.pdf`.
4. Use the **+ / −** zoom controls in the preview header to zoom in or out.
5. Drag the center divider to resize panels.

Use the sidebar to switch between **Home** (your resumes), **Library** (template browser), and **Cover Letters**.

### Cover Letters

1. Open **Cover Letters** in the sidebar.
2. Click **+ New Cover Letter**, pick a template, and edit YAML with live preview.
3. Choose a letter template from the editor dropdown (Classic, Modern, Minimal, etc.).
4. Set `signature_name` for the script-font signature in the bottom-right.
5. Click **Download PDF** — saved as `[Name] Cover Letter.pdf`.

Cover letter YAML supports `date: auto` to insert today's date when rendered.

### Resume YAML Structure

```yaml
name: Your Name

contact:
  email: you@email.com
  phone: (555) 123-4567
  location: City, ST
  linkedin: linkedin.com/in/you

summary: |
  Brief professional summary...

experience:
  - title: Job Title
    company: Company Name
    location: City, ST
    start: Jan 2020
    end: Present
    bullets:
      - Achievement with measurable impact
      - Another accomplishment

education:
  - degree: B.S. Degree Name
    school: University Name
    location: City, ST
    year: "2020"

skills:
  - "Category: Skill1, Skill2, Skill3"
```

### Cover Letter YAML Structure

```yaml
name: Your Name

contact:
  email: you@email.com
  phone: (555) 123-4567
  location: City, ST
  website: yourportfolio.com

date: auto  # or "March 15, 2026"

recipient:
  company: Company Name
  hiring_manager: Hiring Team
  title: Position Title
  address: City, ST

salutation: Dear Hiring Team,

body: |
  First paragraph...

  Second paragraph...

closing: Sincerely,
signature_name: Your Name
```

## PDF Download Approach

PDF export uses **dom-to-svg** + **svg2pdf.js** to build vector PDFs from the on-screen preview (not screenshots). Resume downloads are named **`Doherty Resume.pdf`**. Cover letters download as **`[Name] Cover Letter.pdf`**.

The signature uses the **Great Vibes** Google Font (script-style signature) in preview and PDF. Body text uses **Libre Baskerville** or **Inter** depending on the template. Preview zoom only affects the display — exported PDFs are always full US Letter size.

## Build for Production

```bash
npm run build
```

This writes a standalone `index.html` and `assets/` folder at the project root (relative paths, no server needed). Open `index.html` in Chrome to use it.

For a local preview over HTTP instead:

```bash
npm run preview
```
